# Новый приём движения

Приём, которого нет в `docs/motion.md`, не существует. Порядок:

1. **Зачем.** Одна фраза: какую иерархию приём усиливает и в какой секции. Если фраза не складывается – приём не нужен, взять из реестра.
2. **Описание** в `docs/motion.md`, таблица реестра: имя (латиницей, через дефис), что делает, параметры по умолчанию (длительность, easing из токенов, шаг), для чего. Штампы движения из раздела 2 TASTE.md – проверить, что это не один из них без оправдания.
3. **Токены.** Новый easing или длительность – сначала `styles/tokens.css` (`--ease-*`, `--dur-*`) и база, потом код. В JS числа длительностей допустимы, easing читается из токена через `css('--ease-…')`.
4. **Реализация** в `js/motion.js`, объект `PRESETS`: подготовить состояние → `ready(el)` → твин с `scrollTrigger: trigger(el)`. Один раз, `start: top 85%`. Для scrub – `scrub: 1`, без `once`. Маски SplitText после появления снимать (`split.revert()`).
5. **Проверка.** Без `?static`: появляется, не залипает, при возврате не повторяется. С `?static` и `prefers-reduced-motion`: всё видно, вёрстка та же. Во встроенном браузере при скрытой панели – через `gsap.ticker.tick()` и `gsap.getProperty`.
6. **Запись.** Журнал в `docs/design-system.md`: приём, секция, файлы. Пин-секция – проверить, что она одна на странице.
