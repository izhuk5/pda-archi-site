# Проверка

Отчёт – числами. «Проверил» без чисел не принимается.

1. `npm run check` – список замечаний по файлам и строкам: сырые значения вне токенов (цвет, размер, длительность, easing, вес, интерлиньяж, z-index), несуществующие `var(--…)`, размер текста числом, капс, моно, спейсеры, закомментированный код, `hidden`-блоки, длинное тире, точка-разделитель, `<img>` вместо `<Image>`, `<Image>` без `alt`, `data-reveal` вне реестра, расхождение реестра и токенов с документацией, `id` секций не по карте, тестовый объект сцены, структура (папка `Name/` с подключёнными `Name.css` и `Name.js`, классы с префиксом блока, GSAP только из `src/lib/gsap.js`, своё движение через `onMotion()`, импорты между папками через алиасы), имена классов только kebab-case, desktop-first (только `max-width: 1023px | 767px | 478px`, по убыванию), справочник `docs/libraries.md` против `src/lib/gsap.js` и `package.json`. Проверяет все `.astro` в `src/`, CSS и JS секций и компонентов, `src/styles/`, `src/lib/`. Довести до 0. Затем `npm run build` – без ошибок.
2. `npm run shot -- [id]` (концепт – `--page concepts/hero-a`) – скриншоты в `scripts/out/`: `desktop-1440*.png`, `mobile-390*.png`, длинная страница – кусками. Открыть все и посмотреть глазами: обрезанные слова, тексты на неверном фоне, элементы за краем.
3. Горизонтальный скролл на 390 – в отчёте `shot.mjs`: число и список виновников с координатами. Должно быть 0.
4. Висячие строки – в отчёте `shot.mjs` на обеих ширинах: блоки, где в последней строке одно слово. Блоки с `<br>` – поставить `&nbsp;`. Ошибки консоли и сети – там же, должно быть 0.
5. Движение: открыть без `?static`, убедиться, что всё появляется, ничего не залипло; при `prefers-reduced-motion` всё видно сразу.
6. Итог в отчёте: таблица «проверка – число» и что исправлено.
