Ты проверяешь секцию (или весь сайт) по Definition of Done из `CLAUDE.md`. Ничего не правишь – только отчёт.

1. Запусти `python3 scripts/check.py` и приведи вывод: число замечаний по категориям, файлы и строки.
2. Запусти `scripts/shot.sh <id>` (или без id для всей страницы) и открой `scripts/out/desktop-1440.png` и `scripts/out/mobile-390.png`. Опиши, что видишь глазами: обрезанные слова, текст на неверном фоне, элементы за краем, пустые зоны.
3. Пройди по пунктам DoD и для каждого напиши «да / нет» и число, где оно есть: сырых значений, спейсеров, элементов без `data-reveal`, `id` не по карте.
4. Сверь тексты секции с `brief/brief.md`: перефразированные без пометки «предлагаю заменить» – назвать.
5. Итог: готово / не готово, и список того, что мешает, в порядке важности.
