# Старт нового проекта (сайт кодом через Claude Code)

## Что положить в папку проекта
Скопировать эту заготовку целиком. В ней:
Нужны Node 22+ и Google Chrome; npm не нужен. После копирования – `git init` и первый коммит, если папка пришла без `.git`.
- `CLAUDE.md` – правила, пайплайн, DoD, грабли. Не редактируется под проект, переезжает между проектами. Claude Code читает его сам в каждом чате.
- `brief/source/` – сюда кидаешь бриф клиента как есть (pdf, docx, txt, скриншоты, письмо).
- `brief/brief.md`, `brief/references.md` – бриф и референсы в едином формате. Заполняет Claude из сырого брифа.
- `docs/design-system.md` – живое состояние проекта. Пустой скелет, Claude заполняет по ходу.
- `docs/TASTE.md`, `docs/motion.md`, `docs/scene.md` – принципы: вкус, движение, 3D. Без цветов и размеров, только как принимать решения.
- `styles/`, `js/`, `index.html` – каркас сайта, уже подключены GSAP, Lenis и Three.js с CDN.
- `.claude/skills`, `.claude/agents` – процессы «собери секцию», «критика», «проверь», «новый приём», «3D в секции».

## Первый промпт в новом чате (вставь как есть)

Мы начинаем сайт кодом через Claude Code. Правила работы в CLAUDE.md – прочитай и соблюдай.
1. В папке brief/source лежит бриф клиента в его формате. Прочитай всё и переведи в brief/brief.md по шаблону, референсы – в brief/references.md словами. Чего в брифе нет – запиши в «Открытые вопросы», не выдумывай.
2. Заполни в docs/design-system.md раздел «Контекст» и «Карта секций» из брифа: у каждой секции – роль в аргументе, поверхность, приём движения, есть ли 3D, адаптируется или стекается.
2a. Прочитай docs/TASTE.md и запиши в «Принятые решения» направление в одну фразу, три ручки, фирменный приём и список штампов, которых здесь не будет. Если фирменный приём – движение или 3D, скажи это прямо и сверься с docs/motion.md и docs/scene.md.
3. Затем hero: 2–3 направления отдельными файлами в concepts/ (hero-a.html, hero-b.html…), каждый со своими токенами в :root внутри файла, с реальным текстом из брифа. Сними скриншоты 1440 и 390 каждого варианта (node scripts/shot.mjs --page concepts/hero-a.html) и покажи. До моего выбора остальные секции не трогай.
Возвращай список изменённых файлов.

## Промпт после выбора направления

Выбираю вариант [a/b/c]. Перенеси его токены в styles/tokens.css и в docs/design-system.md раздел «Токены», собери hero в index.html как секцию из карты по скиллу section: движение по docs/motion.md, проверка node scripts/check.mjs, скриншоты 1440 и 390, три вопроса критики, DoD, ручная доводка, журнал. Остальные секции не трогай.

## Промпт для продолжения в новом чате

Продолжаем проект. Прочитай CLAUDE.md, LOG.md, brief/brief.md и docs/design-system.md, открой файлы из раздела «Как продолжить в новом чате» и скажи, что изменилось с последней записи в журнале (git log и git diff). Подними локальный сервер и сними скриншот текущего состояния. Потом жди задачу.
