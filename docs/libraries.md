# Библиотеки и плагины – подсказка

Справочник: что стоит в проекте и что можно подключить, когда понадобится. Открывать перед тем, как писать движение, 3D или искать «как сделать X» – возможно, готовый плагин уже есть.

Версии здесь не пишутся – они в `package.json` (точные) и проверяются `npm run versions`. Подключили новое – отметка ✅ в таблице, одна фраза «зачем» в `LOG.md`. `npm run check` сверяет отметки GSAP-плагинов с `src/lib/gsap.js` и список пакетов с `package.json`.

## В проекте

| Пакет | Зачем | Где подключается |
|---|---|---|
| `astro` | сборка сайта, компоненты, оптимизация картинок | `astro.config.mjs` |
| `gsap` | движение: появление, скролл, таймлинии | только `src/lib/gsap.js`, остальные берут оттуда (`@lib/gsap.js`) |
| `lenis` | плавный скролл | `src/lib/main.js` |
| `three` | 3D-сцена | `src/lib/scene.js`, грузится лениво, только при `[data-scene]` |
| `prettier` (dev) | форматирование JS: одна команда на строку, длинные твины – по свойству в строке | `npm run format` (`src/**/*.{js,astro,css}`), в VS Code – при сохранении JS, `.astro` и CSS (`.vscode/settings.json`, расширение `esbenp.prettier-vscode`); настройки – `.prettierrc.json`; в сборку не попадает |
| `prettier-plugin-astro` (dev) | Prettier понимает `.astro`: frontmatter, разметку, `<script>` | подключён в `.prettierrc.json` (`plugins`, `parser: astro`) |

## GSAP: плагины

Все бесплатные и уже лежат в пакете `gsap` – ставить ничего не надо. Подключение – три строки в `src/lib/gsap.js`:

```js
import { Flip } from 'gsap/Flip';      // 1. импорт
gsap.registerPlugin(..., Flip);         // 2. регистрация
export { ..., Flip };                   // 3. экспорт – дальше import { Flip } from '@lib/gsap.js'
```

Каждый подключённый плагин попадает в сборку целиком, даже если не используется, – поэтому подключаем по мере надобности. Новый приём движения на плагине – сначала описание в `docs/motion.md`.

### Скролл
| Плагин | Что делает | Когда брать | У нас |
|---|---|---|---|
| `ScrollTrigger` | запускает и «прокручивает» анимации по скроллу, пин секций | почти всегда | ✅ |
| `ScrollSmoother` | плавный скролл с параллаксом | не брать: у нас Lenis, вместе они конфликтуют | |
| `ScrollToPlugin` | плавная прокрутка к элементу или позиции | не нужен: якоря делает `lenis.scrollTo` | |
| `Observer` | ловит колесо, свайп, касание без настоящего скролла | полноэкранные «слайды» на колесо | |

### Текст
| Плагин | Что делает | Когда брать | У нас |
|---|---|---|---|
| `SplitText` | режет текст на строки, слова, буквы для анимации | появление заголовков (`lines`, `chars`) | ✅ |
| `ScrambleTextPlugin` | текст «перебирает» случайные символы до финального | штамп из TASTE.md – только с одной фразой «зачем» | |
| `TextPlugin` | текст печатается или заменяется по буквам | эффект печатной машинки, смена слов | |

### SVG
| Плагин | Что делает | Когда брать | У нас |
|---|---|---|---|
| `DrawSVGPlugin` | линия SVG «рисуется» | подчёркивания, схемы, подписи от руки | |
| `MorphSVGPlugin` | одна SVG-фигура превращается в другую | смена иконок, морфинг форм | |
| `MotionPathPlugin` | элемент движется по SVG-кривой | путь объекта, «полёт» по траектории | |
| `MotionPathHelper` | редактор кривой прямо в браузере | только во время разработки, в сборке не оставлять | |

### Перетаскивание и физика
| Плагин | Что делает | Когда брать | У нас |
|---|---|---|---|
| `Draggable` | перетаскивание мышью или пальцем | слайдеры, карусели «тянуть рукой» | |
| `InertiaPlugin` | инерция после броска | вместе с `Draggable` | |
| `Physics2DPlugin` | 2D-физика: скорость, угол, гравитация | разлетающиеся элементы, конфетти | |
| `PhysicsPropsPlugin` | физика для любого свойства | редко | |

### Кривые (easing)
| Плагин | Что делает | Когда брать | У нас |
|---|---|---|---|
| `CustomEase` | свои кривые плавности | наши токены `--ease-*` из `tokens.css` | ✅ |
| `CustomBounce` | настраиваемый отскок | «пружинящие» элементы | |
| `CustomWiggle` | настраиваемое покачивание | встряска, внимание к элементу | |
| `EasePack` | дополнительные кривые: `SlowMo`, `RoughEase`, `ExpoScaleEase` | `ExpoScaleEase` – плавный зум | |

### Раскладка
| Плагин | Что делает | Когда брать | У нас |
|---|---|---|---|
| `Flip` | плавный переход между двумя раскладками (фильтр, раскрытие карточки) | смена сетки, «карточка разворачивается» | |

### Отладка
| Плагин | Что делает | Когда брать | У нас |
|---|---|---|---|
| `GSDevTools` | панель-таймлайн: пауза, перемотка, скорость | отладка сложной таймлинии, в сборке не оставлять | |

### Для чужих движков и устаревшее
| Плагин | Что делает | Когда брать | У нас |
|---|---|---|---|
| `PixiPlugin` | анимация объектов PixiJS (2D на WebGL) | только если на сайте есть PixiJS | |
| `EaselPlugin` | анимация объектов EaselJS (canvas) | только если на сайте есть EaselJS | |
| `CSSRulePlugin` | анимация `::before` / `::after` | не брать: устарел, вместо него – CSS-переменная, которую анимирует GSAP | |

## Three.js: аддоны

Лежат в пакете `three`, ставить не надо. Импорт – из `three/addons/…`, только внутри `src/lib/scene.js` (так они попадают в ленивый файл сцены, а не в общий). Правила сцены – `docs/scene.md`.

| Аддон | Импорт | Когда брать |
|---|---|---|
| `GLTFLoader` | `three/addons/loaders/GLTFLoader.js` | загрузка модели `.glb` |
| `DRACOLoader` | `three/addons/loaders/DRACOLoader.js` | модели сжаты Draco (наше правило – всегда); файлы декодера скопировать из `node_modules/three/examples/jsm/libs/draco/` в `public/draco/` и указать `setDecoderPath('/draco/')` |
| `KTX2Loader` | `three/addons/loaders/KTX2Loader.js` | сжатые текстуры `.ktx2` (лёгкие для видеокарты) |
| `RoomEnvironment` | `three/addons/environments/RoomEnvironment.js` | мягкий студийный свет без файла HDRI |
| `HDRLoader` | `three/addons/loaders/HDRLoader.js` | окружение из `.hdr` (бывший `RGBELoader` – устарел с r180) |
| `OrbitControls` | `three/addons/controls/OrbitControls.js` | вращать модель мышью; на лендинге обычно не нужен – движение по скроллу |
| `EffectComposer` | `three/addons/postprocessing/EffectComposer.js` | постобработка (блюр, свечение) – дорого, только с замером кадра |

## Lenis

Плавный скролл, у нас на тикере GSAP (`src/lib/main.js`). Настройка – `lerp` (0.1: чем меньше, тем «тяжелее» скролл). Якоря – `lenis.scrollTo`, `scroll-behavior: smooth` в CSS не ставится. Стили Lenis подключены (`lenis/dist/lenis.css`).

## Astro: встроенное

| Что | Зачем | Статус |
|---|---|---|
| `<Image>`, `<Picture>` из `astro:assets` | WebP/AVIF, размеры, `srcset`, `loading` сами | используем (правило в CLAUDE.md) |
| `fonts` в `astro.config.mjs` | локальные шрифты с оптимизацией и preload | когда перейдём с Google Fonts на локальные |
| `astro:transitions` (View Transitions) | плавные переходы между страницами | не берём: сайт одностраничный, а после каждого перехода Lenis и ScrollTrigger пришлось бы запускать заново |
