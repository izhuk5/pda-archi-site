# Публикация

Сайт статический: `index.html`, `styles/`, `js/`, `assets/`. Всё остальное (`brief/`, `docs/`, `concepts/`, `scripts/`, `.claude/`) на хостинг не уезжает.

## Перед выкладкой
1. `python3 scripts/check.py` – 0 замечаний.
2. `scripts/shot.sh` – скриншоты 1440 и 390 последнего состояния просмотрены.
3. Поднять `?v=N` у `styles/*.css` и `js/*.js` в `index.html`, иначе браузеры возьмут старые файлы из кеша.
4. Видео – только пережатые в `assets/video/`, модели – только сжатые в `assets/models/`.

## Варианты
- **GitHub Pages**: репозиторий → Settings → Pages → ветка `main`, папка `/`. Адрес `https://<user>.github.io/<repo>/`. Пути в `index.html` относительные, поэтому работает как есть.
- **Netlify Drop**: перетащить папку с четырьмя элементами выше на app.netlify.com/drop. Для повторной выкладки – Netlify CLI или подключить репозиторий.
- **Свой сервер** (nginx): папка сайта, `try_files $uri $uri/ =404`, кеш ассетов 30 дней, `index.html` без кеша, gzip. Выкладка – `rsync` только перечисленных путей.

Хостинг выбирается один раз и записывается в `LOG.md` вместе с адресом.
